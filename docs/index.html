Safety

Know the risk before you apply

Many cleaners don’t tell you what they touch. In WinCleaner every item has a risk level, and Dangerous options stay locked until you enable them in Settings.

  • Four risk levels

    Every option is rated Safe, Caution, Dangerous or Blocked. Critical components such as RpcSs and WinDefend are Blocked and can never be changed.

  • Restore point first

    By default, WinCleaner creates a System Restore point before applying changes, so you can roll Windows back if something goes wrong.

  • Session undo

    Every change is recorded in a session journal, and Global Undo reverts everything that can be reversed.

  • Build-aware

    Options that don’t apply to your Windows version, edition or architecture are hidden automatically, so nothing fails halfway through.

Before you start

WinCleaner changes Windows services, registry values, scheduled tasks and AppX packages. Keep System Restore enabled, read each option before applying, and start with a preset instead of selecting everything. Releases are not code-signed, so verify the download against SHA256SUMS.txt before running it.

Know the risk before you apply

Many cleaners don’t tell you what they touch. In WinCleaner every item has a risk level, and Dangerous options stay locked until you enable them in Settings.

  • Four risk levels

    Every tweak has a Safe, Caution, Dangerous or Blocked risk level. Knowing the risk before you feel it the hard way is every user’s right.

  • Restore point first

    If some settings backfire on your PC or you dislike what you applied, roll everything back with the Restore Point WinCleaner created.

  • Undo the session

    Every change is recorded in a session journal, and Global Undo reverts everything that can be reversed.

  • Build-aware

    Options that don’t match your Windows version, SKU or architecture are not offered; every setting is shown only when it fits your Windows build.

Before you start

WinCleaner changes Windows services, registry values, scheduled tasks and AppX packages. Keep System Restore enabled in Windows, read each option before applying, and start with a preset instead of selecting everything. If something backfires, you can roll back.

New release

v2.6.0 release notes

Feature updates

  • Microsoft Edge removal: Added because of strong demand to fully remove Windows’ built-in browser, Microsoft Edge.
  • Separate file extensions and hidden files: Show or hide file extensions and show or hide hidden files are no longer one switch. They are now separate options, by request.
  • Helium Browser support: Helium Browser was added to the installer / winget list as an alternative browser, by request.
  • Installer search box: The Installer page now has a search bar so you can find apps.
  • Removed bloatware apps no longer appear in the list.

Bug fixes

  • Restore point: Fixed a warning that said a restore point could not be created even when one existed, because Windows only allows a new point about once every 24 hours.
